PLAY ON YOUR COMPUTER

A JDK. A terminal. Your next move.

Install Java JDK 17 or later, then download the source ZIP or clone the repository. Open a terminal in the project folder.

Windows

.\compile.bat
.\run.bat

Use PowerShell or Command Prompt.

macOS / Linux

bash compile.sh
bash run.sh

Run these commands from your terminal.

The game runs on your computer. This website hosts the guide and API reference. Network multiplayer uses a separately run TCP server; it is not hosted by this page.
